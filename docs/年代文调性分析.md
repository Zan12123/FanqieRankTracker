# 年代文调性分析

---

## 自然涌现的调性类型

从 40 条简介实际内容中聚类，涌现出以下调性维度：

| 调性      | 核心识别信号                           | 典型简介句式                                                                       |
| ------- | -------------------------------- | ---------------------------------------------------------------------------- |
| **甜宠**  | 强调"宠"是主线，男主的无底线包容/追逐是核心卖点        | "他把她宠上天""冷面军官红眼堵门""掐腰哄""越缠越紧"                                                |
| **爽文**  | 密集反转/打脸/复仇/觉醒，冲突密度高，读者爽感来自女主主动出击 | "手撕渣男""抢金手指""踹了""让她吃屎""全部送走""告状至陆海空三军"                                       |
| **轻松**  | 幽默/俏皮/乌龙/闹剧，笑声是主要阅读驱动力           | "白天惹祸夜里撩拨""认错夫洞错房""洗脑洗成恋爱脑""我洗洗还是很耐看的"可以闹腾/错位/乌龙，但不能"对年代规则不care"——年代不幸不能成为笑料 |
| **日常**  | 家长里短/成长/团宠/救赎，节奏舒缓，温暖是底色         | "努力学习爱好吃瓜""小保姆自考""日常家长里短+互相救赎"                                               |
| **女强**  | 女主独立事业线/不靠男人/自我实现                | "不靠男人不等豪门""从一无所有到一字千金""女兵王灵魂"自考/从商/写作/——合法框架内的个体崛起                           |
| **欲望**  | 身体吸引力驱动/野性/张力/糙汉                 | "高粱地里再也忍不住""翻窗夜会""奶香是唯一的药"                                                   |
| **奇幻**  | 年代背景融入非现实元素（妖狐/灵气/神兽）            | "上古九尾狐""人参爷爷""熊猫一拳打穿坦克""拖家带口大妖来投奔"                                           |
| **反套路** | 刻意违背年代文常规期待/利己女主/无固定cp           | "精致利己不善良""不用善良也能活得好""无固定cp"                                                  |

> 一本书通常由 1-2 个调性维度组合而成，如"甜宠+生子""爽文+碾压""轻松+错位""奇幻+沙雕"。标签格式为"主调性+副特征"，如"甜宠+追妻""爽文+觉醒""轻松+闹腾"。

## 年代文调性的五个品类独特维度

年代文的调性体系有五个独特之处：

### 1. 奇幻调性——现实主义底色的最大反差

年代文是唯一拥有独立"奇幻"调性的品类（九尾狐/灵兽/灵气/神兽/修仙）。年代文允许"人参爷爷+熊猫一拳打穿坦克"在不破坏年代感的前提下成立。

根本原因：年代困境越真实，奇幻元素的解压效果越强。"硬现实主义底色"的物理限制感与"非现实元素"的无限自由感形成最大张力反差。已验证年代×奇幻是差异化赛道。

### 2. 五大硬约束对调性的过滤机制

年代文有"物理约束过滤调性"机制的品类。5 个硬约束（所有制规则/婚恋规则/个人权利边界/政策环境/单位-社会控制）构成了一套调性准入门槛——不是所有调性都能在年代背景成立。

## 调性判断流程

```
简介文本
    │
    ├── Step 1: 看作者自标标签区
    │   简介开头的【】或[]内的关键词是最直接的信号。
    │   如："爽文，双洁甜宠" → 爽文+甜宠
    │   如："日常+甜文+发家致富" → 日常
    │   如："军婚+穿越+甜宠" → 甜宠
    │   注意：自标偶尔不准，需用正文信号交叉验证。
    │
    ├── Step 2: 看核心事件的冲突等级
    │   公开碾压/连环反杀/复仇 → 爽文
    │   乌龙/闹剧/阴差阳错 → 轻松
    │   攻略男主/被追/爱宠 → 甜宠
    │   学习/自考/种田/做菜 → 日常
    │   独立事业/不靠男人/自我实现 → 女强
    │   压抑爆发/翻窗/野合 → 欲望
    │   妖狐/灵兽/修仙元素 → 奇幻
    │
    ├── Step 3: 看女主行动姿态
    │   被动承受→被选中→甜宠
    │   主动出击→反杀/掀桌→爽文
    │   闹腾/打打闹闹→轻松
    │   安静成长/不争不抢→日常或写实
    │   伪装/装弱→奇幻或甜宠
    │
    └── Step 4: 综合判定
       以简介中最突出的卖点为主调性，次要特征为副标签。
       一本书可以有多个调性维度，但主调性只有1个。
       示例："装弱真强+九尾狐妖+沙雕画风" → 奇幻+沙雕
```

## 关键发现

1. **甜宠和爽文是两大核心调性**——甜宠主导新书榜（40%），爽文主导阅读榜（55%）。即"开书靠甜宠，留人靠爽文"。

2. **轻松向在新书榜占比 20%，阅读榜降至 10%**——轻松向开局友好但长线留存不如爽文向和甜宠向。

3. **奇幻是阅读榜的独立调性，新书榜未出现**——年代×奇幻（《小狐狸崽》48万在读）是已验证的差异化赛道，但新书榜尚未跟进。

4. **欲望/张力向（糙汉文）双榜分布一致**——新书榜#8、阅读榜#9，均有固定位置，受众精准。

5. **女强/独立向在新书榜有一定量，阅读榜仅1本（#15兵王线）**——女强向开书容易留存难，纯事业线缺少感情锚点。

6. **简介自标与内容实际调性存在偏差**——如#2小狐狸崽简介偏"沙雕找爹"但节奏实为爽文向，判定时应以事件选取和冲突密度为主，作者自标为辅助。
