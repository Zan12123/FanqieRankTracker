# 故事核生成工作流

> 配合各题材"核心设计"文件使用。每个题材的核心设计提供变量取值空间，工作流提供统一的 5 步生成管道。

---

## 总览

```
                ┌─────────────────────┐
                │  题材核心设计文件     │ ← 每个题材一份（如 宫斗宅斗_核心设计.md）
                │  · 情感基因          │
                │  · 变量清单(A-F六层)  │
                │  · 核心公式          │
                │  · 禁区清单          │
                └─────────┬───────────┘
                          │
                          ▼
┌──────────────────────────────────────────────────────┐
│                  故事核生成工作流（本文档）              │
│                                                      │
│  Step 1 ──→ Step 2 ──→ Step 3 ──→ Step 4 ──→ Step 5 │
│  选题材      选路径      填模板      变量变异    禁区校验 │
└──────────────────────────────────────────────────────┘
                          │
                          ▼
                    ┌──────────┐
                    │  故事核   │
                    │  + 大纲骨架 │
                    └──────────┘
```

## Step 1: 选题材 → 加载核心设计

选择目标题材分类，加载对应的核心设计文件。

**核心设计提供的输入**：
- **情感基因**：该题材的核心情绪底色（安/宠/夺/燃/虐...）+ 情绪落点链
- **A-F 六层变量清单**：每层的取值空间 + 规则 + 禁区
- **核心公式**：新书榜公式（前 3 章是什么决定留存）+ 阅读榜公式（30 万字是什么决定追读）
- **禁区清单**：该题材绝对不能碰的东西
- **题材独有优势**：该题材相比其他品类的差异优势
- **差异化手术刀**：建议动的变量（按风险排序）

**当前可用题材**：宫斗宅斗

---

## Step 2: 选榜单路径

| 路径 | 目标 | 使用公式 | 爽感金字塔 | 适用场景 |
|------|------|---------|-----------|---------|
| **新书榜路径** | 前 3 章留存 | 题材核心公式的新书榜部分 | 只需底层爽感 | 新作者开书、测试题材反馈 |
| **阅读榜路径** | 30 万字追读 | 题材核心公式的阅读榜部分 | 底层→中层→顶层完整递进 | 有经验作者、冲刺头部排名 |
| **双榜通吃** | 全周期覆盖 | 基础打底 + 中期展开升级变量 | 底层开局 → 中层接上 → 顶层收束 | 最理想但设计难度最高 |

**决策规则**：
- 如果目标是"先写出来看看" → 新书榜路径，只设计底层
- 如果目标是"冲阅读榜前 20" → 阅读榜路径，必须设计完整递进链（最重要：底层翻完接什么）
- 如果目标是"头部爆款" → 阅读榜路径 + 在 B-顶层爽感或 C-男主类型做差异化

---

## Step 3: 填故事核模板

从题材核心设计的变量清单中抽取值，填入模板。

### 故事核模板

```
【世界观】
在 [A.安全距离类型] 的设定下，

【主角】
一个拥有 [C.女主开局姿态] 的女主（[C.道德合法性]赋予她"该得"的资格），

【绑定】
因 [C.绑定方式] 与 [C.男主类型] 绑定，

【金手指】
以 [D.金手指类型] 作为 [D.金手指功能]，

【环境】
在 [D.集体功能] 的环境中，

【爽感递进】
经历 [B.底层爽感 → B.中层爽感 → B.顶层爽感] 的递进，

【落点】
最终达成 [核心情绪落点]。

【结局向量】
女主终极状态：[F.女主终极状态]
男主终极行动：[F.男主终极行动]
情感关系落点：[F.情感关系落点类型]

【标签】
调性：[E.主调性+副特征]
创新切口：[在 A/B/C/D/E/F 哪一层做差异化，具体变量名]
榜单路径：[新书/阅读/双榜]
```

### 填写规则

| 规则 | 说明 |
|------|------|
| **必填变量** | 安全距离类型、女主开局姿态、道德合法性、绑定方式、男主类型、底层爽感、核心情绪落点、主调性、女主终极状态、情感关系落点 |
| **新书榜路径可空** | 中层爽感、顶层爽感（新书榜只需底层，但建议预留升级空间防止 10 万字触顶） |
| **新书榜路径结局可简** | 男主终极行动在新书榜阶段只需方向性指示（如"男主最终___"），不需要完全确定 |
| **默认值** | 不指定时，默认取核心设计中该变量的"新书榜取值" |
| **创新切口** | 必须明确在哪个变量层创新，不写"多方面创新"（会失去差异化的锋利度） |
| **结局与开局呼应** | F-情感关系落点必须与 B-底层爽感有呼应——清算开局→掌控反转/盟约达成，自主开局→盟约达成/自主超越 |

---

## Step 4: 变量层变异

固定其他变量，每次换一个变量层的取值，生成故事核变体。

### 变异矩阵

| 变异层 | 操作 | 产出 | 风险 |
|--------|------|------|------|
| E-调性组合 | 换主调性+副特征 | 同一故事核的不同风格版本 | 🟢 低 |
| C-绑定方式 | 换绑定方式 | 同一个"她"的不同开场 | 🟢 低 |
| F-结局向量 | 换女主终极状态/情感关系落点 | 同一旅程的不同终点 | 🟡 中 |
| C-男主类型 | 换男主类型 | 同一女主的不同情感线 | 🟡 中 |
| D-金手指 | 换金手指类型 | 同一困境的不同解法 | 🟡 中 |
| B-爽感递进链 | 换中层/顶层路径 | 同一开局的不同长篇走向 | 🔴 高 |
| A-安全距离 | 换安全锚类型 | 同一情绪的不同世界设定 | 🔴 高（接近跨题材） |

### 变异规则

1. **每次只动一个变量层**，其他层保持不变
2. **变异后必须过 Step 5 校验**
3. **跨题材变异**（如把宫斗的绑定方式用到年代文）+ 需确认目标题材的禁区允许
4. **调性变异注意留存规律**：确认该调性在目标榜单路径的留存数据（如强制爱在宫斗阅读榜归零）

## Step 5: 题材规则校验

对照题材核心设计的"禁区清单"，逐项检查生成的故事核。

### 通用校验清单

```
□ 女主道德合法性：她的"该得"是否成立？读者会共情还是反感？
□ 开局姿态：是否足够低/弱？前3章的代入感够吗？
□ 调性留存：所选主调性在目标榜单路径是否有留存风险？
□ 金手指匹配：金手指功能是否对应该题材的核心焦虑源？
□ 认证机制：社会认证是否即时/有效？（宫斗必须即时，年代可以渐进）
□ 绑定合法性：绑定方式是否有道德合法性？（被逼 vs 主动程度）
□ 爽感断层：底层翻完后有没有接中层？（10万字触顶是最大死因）
□ 单调性风险：是否需要在中段切换调性主轴？
□ 结局呼应：情感关系落点是否与开局爽感类型呼应？（清算→掌控反转，自主→盟约达成/自主超越）
□ 结局深度：是否停在"追到了"就结束？追到后的关系质变是什么？
□ 关系弧线：男主从头到尾有无变化？30万字需要关系有进化弧线
```

### 题材特定校验

```
□ [题材特定禁区 1]
□ [题材特定禁区 2]
□ ...
```

任何一项 ❌ → 回 Step 3 修改对应变量，重新过校验。

## 示例：宫斗宅斗·新书榜路径

**Step 1**: 加载 `宫斗宅斗_核心设计.md`
**Step 2**: 新书榜路径 → 只需底层爽感，调性任选
**Step 3**: 填模板

```
【世界观】
在后宫/宅院（封闭系统，生存级威胁）的设定下，

【主角】
一个拥有 表面顺从、内里清醒（信息差模型）的女主（前世被夺走一切，赋予她"该得"的资格），

【绑定】
因 被逼为通房 与 腹黑侯爷 绑定，

【金手指】
以 重生记忆 作为 生存兜底+信息优势+情感锚定三合一，

【环境】
在 对手即时打脸认证（延迟的爽感不成立）的环境中，

【爽感递进】
经历 身份翻盘（通房→宠妾）→ [中期预留：接清算复仇，背后更大的敌人浮出] → [远期预留：规则制定] 的递进，

【落点】
最终达成 让夺走她东西的人承认"你赢了"。

【标签】
调性：爽文+重生
创新切口：C-男主类型——用 残王 替代标准冷面权臣（男主前世为她而死，今生第一件事嫁给他）
榜单路径：新书榜（中期留了清算升级空间，防止10万字触顶）

【结局向量】
女主终极状态：登顶（通房→宠妾→侯府主母）
男主终极行动：[新书榜阶段暂定方向：追悔跪求——前世冷眼旁观，今生她成了他够不到的人]
情感关系落点：掌控反转（从"被掌控的通房"到"她选择离开时他跪下了"）
```

**Step 5**: 校验通过 ✓
- 道德合法性：前世被夺走一切，成立 ✓
- 开局姿态：通房=够低 ✓
- 调性安全：爽文+重生是宫斗安全组合 ✓
- 金手指匹配：重生=宫斗最强金手指 ✓
- 认证即时：打脸设计在第2-3章 ✓
- 爽感断层：预留了中期清算接入点 ✓

## 示例：宫斗宅斗·阅读榜路径

**Step 1**: 加载 `宫斗宅斗_核心设计.md`
**Step 2**: 阅读榜路径 → 需要完整三层爽感递进链
**Step 3**: 填模板

```
【世界观】
在后宫/宅院（已进化为情感安全阶段：读者知道她不会死，焦虑从"生存"转向"情感"）的设定下，

【主角】
一个拥有 不藏了直接释放（释放型）的女主（前世灭门+重生后第一步就是清算+人格厚度赋予她"制定新规则"的资格），

【绑定】
因 重生后主动选择嫁他 与 残王（前世为她闯宫而死）绑定，

【金手指】
以 重生记忆（已内在化为直觉+经验）作为 信息优势+情感锚定，

【环境】
在 团宠扩散（残王府势力+民间声望+朝堂旧部+对手被迫认可）的环境中，

【爽感递进】
经历 清算复仇（恶母换子真相→嫡姐夺位→朝堂敌人，三层递进清算）→ 情感独占确认（残王从头宠到尾，中间"动摇"实为保护她）→ 规则制定（不入后宫，女子入朝堂倒反天罡）的递进，

【落点】
最终达成 不只夺回了被偷走的整个人生，还重新定义了"赢"的规则——不是她争到了宠，是她制定的规则让所有人争。

【标签】
调性：爽文+重生
创新切口：B-爽感顶层——用"女子入朝堂"替代传统"登后位"，夺的终极形态从"争宠登顶"变成"另起规则"
榜单路径：阅读榜

【结局向量】
女主终极状态：规则制定（不入后宫，女子入朝堂倒反天罡）
男主终极行动：盟约并肩（从"他保护她"到"一起打天下"）
情感关系落点：盟约达成（不是她靠他登顶，是一起打出了新规则）
```

**Step 5**: 校验通过 ✓
- 清算层级递进：恶母→嫡姐→朝堂，三层 ✓
- 团宠扩散：势力+民间+旧部+对手，四层认证 ✓
- 情感独占：残王从头宠到尾，开篇确认 ✓
- 调性切换：爽文（清算期）→ 甜宠（情感确认期）→ 女强（规则制定期）✓
- 非公式化：差异化变量≥2（残王男主 + 入朝堂替代登后位）✓
- 强制爱转化：无强制爱开局，不需要转化 ✓
- 爽感断层：底层翻盘→中层清算→顶层规则，递进完整 ✓

## 题材核心设计标准

新增题材分析时，核心设计文件必须按以下模板覆盖所有章节：

```
1. 情感基因
   - 核心情绪底色（用一个字定义）
   - 一句话定义
   - 情绪落点链（三次确认路径）
   - 情绪底色 vs 已知题材对照表

2. 变量清单（放规则不放数据，放案例不放榜单）
   - A. 世界观层（安全距离类型 + 新书→阅读进化）
   - B. 情绪层（每种爽感类型的定义+使用边界+递进规则+常见死法）
   - C. 角色层（女主模型+道德合法性来源+男主池+绑定池+适配规则）
   - D. 机制层（金手指功能排序+集体认证形态+调性切换路径）
   - E. 风格层（每种调性的定义+识别信号+适配爽感+风险边界+安全组合）
   - F. 结局层（女主终极状态+男主终极行动+两维交叉落点+开局呼应规则）

3. 核心公式
   - 新书榜公式（前3章留存因子）
   - 阅读榜公式（30万字追读因子）
   - 结局向量公式

4. 禁区清单（生成后逐项校验）

5. 题材独有优势（相比其他品类的差异优势）

6. 差异化手术刀（建议动的变量，按风险排序）
```

> 核心设计 = 分析报告（`底层逻辑分析.md`）的变量化浓缩版。分析报告回答"这个题材是什么样的"，核心设计回答"在这个题材里生成故事核时每个变量能取什么值"。
